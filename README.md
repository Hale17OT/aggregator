# The Aggregator

A source-attributed newspaper reader with Radio, Newsroom, portrait Clips, accounts, interests and Library. This is a **fictional-data local demonstration**, not a production release or live news service. Staff/MFA remains paused; private editorial drafts never enter the reader automatically.

## Architecture

- `apps/web`: Nuxt 4 / Vue 3, selectable server-rendered articles and full numbered bibliographies.
- `apps/api`: Express / TypeScript API, guarded member sessions and media delivery.
- `apps/worker`: deterministic worker boundary; external integrations disabled.
- `apps/mobile`: native Flutter widgets, Android-first with iOS source/configuration. No WebView wrapper.
- `packages`: contracts, eligibility policies, PostgreSQL repositories/migrations, editorial and programme services.
- `fixtures`: explicitly fictional source inputs, taxonomy and policy fixtures.
- `scripts`, `tests`: guarded local tooling, unit/integration checks and preparation scripts.
- `docs/specs`: authoritative specifications, including original Word documents; `docs/execution` records bounded implementation and unresolved gates.

## Source-only setup

Use Node **22.22.3+ within22.x or24.15.0+**, as constrained by `package.json`, and npm. On Windows the existing wrapper selects the workspace Node runtime if present; otherwise install a supported runtime on PATH. Standard npm also works. `.env.example` documents safe memory-adapter defaults; it contains no credentials. Do not supply production URLs.

```powershell
./scripts/npm.ps1 ci
./scripts/npm.ps1 run dev
```

Web: http://127.0.0.1:3000 ; API health: http://127.0.0.1:4000/health. Both bind loopback. Stop the foreground dev stack with Ctrl+C. **Do not run this beside the already-owned local demo supervisor.** Default development uses disposable memory fixtures and does not create authenticated sessions. The checksum-guarded AutoAnimate postinstall patch is included in source.

A fresh clone does **not** contain the23 playable programme renditions, retained accounts/database, APKs, model/tool caches, captured mail, screenshots or review recordings. Missing prepared media is not proof of a player failure. The small fictional source illustration and caption fixture are included; generated video is excluded. No media is downloaded or generated by `npm ci`.

## Full local demo and native app

The existing full demo needs separately prepared, verified workspace-owned PostgreSQL18 data, captured Mailpit delivery, approved local fictional programme assets and a matching target manifest. Do not copy another developer's credentials, retained data or target manifest. Follow [local product execution](docs/execution/OVERNIGHT_PLAN.md), [native local-demo instructions](apps/mobile/LOCAL_DEMO.md), and [database documentation](packages/db/README.md); historical commands are not permission to reset or reseed a retained demo. `demo:start` is for the prepared stopped owned environment, not a generic fresh-clone bootstrap.

Native prerequisites: Flutter compatible with the committed lock (Flutter>=3.38.1, Dart>=3.10), Android SDK/JDK compatible with the committed Gradle9.1 configuration, and an owner-authorized device/emulator. SDK/browser agreements are owner actions. `scripts/flutter-env.ps1` is an existing-workstation wrapper with explicit E:/C: paths; other developers must use their own SDK/cache environment rather than fabricate those paths. Gradle wrapper scripts/JAR and Android/iOS source assets are included; `local.properties`, keys and generated plugins are not.

```powershell
# In apps/mobile, with Flutter and its installed SDKs on PATH:
flutter pub get
flutter test
flutter analyze
flutter build apk --debug --flavor localDemo --target lib/main.dart --dart-define=LOCAL_DEMO=true --no-pub
```

The Android build command was verified at the16 October checkpoint; it is not a current fresh-machine or iOS build claim. On the prepared Windows workstation, `scripts/mobile-loopback.ps1` forwards only web/API/mailbox to the selected device. `scripts/mobile-demo.ps1` builds and installs in place; do not run it merely to inspect source. iOS needs macOS/Xcode and has not been built here.
