## Overlay placement constraint

The inspected first actual clip contains embedded heading in its upper third, evidence label in the middle, evidence sentence below the animated line, and attribution/footer close to the bottom. There is no universally safe lower-left area for a persistent title or caption overlay within this asset. Prefer neutral matte for metadata/captions and right actions outside the contained picture where width permits. A dark canvas alone cannot make white captions over small embedded text safe.
